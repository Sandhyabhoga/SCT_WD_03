
# 🎮 Tic-Tac-Toe Web Application

A colorful and animated web-based Tic-Tac-Toe game with flying ribbon effects upon winning! This project is built using HTML, CSS, and JavaScript.

## ✨ Features
- Interactive 3x3 Tic-Tac-Toe board
- Turn-based gameplay between Player X and Player O
- Flying ribbons celebrate the winner 🎊
- Flip animation on moves
- Reset button to restart the game

## 📁 Project Structure

```
tic-tac-toe/
├── index.html       # Main game HTML
├── style.css        # Styles and animations
├── script.js        # Game logic and effects
```

## 🚀 How to Run

1. Download the project folder.
2. Open `index.html` in any modern web browser.
3. Play and enjoy the game.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Animations & Styling)
- JavaScript (Logic & Interactivity)
